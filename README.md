# JStrimix - Видеохостинг на Java

Полнофункциональная платформа для видеохостинга, разработанная на Java с использованием Spring Boot.

## 🚀 Основные возможности

### Регистрация и аутентификация
- ✅ Регистрация нового пользователя (логин, пароль, email)
- ✅ Авторизация (вход по логину и паролю)
- ✅ Выход из системы
- ✅ Безопасное хранение паролей (BCrypt)

### Работа с видео
- ✅ Загрузка видеофайла с названием и описанием
- ✅ Загрузка превью (изображения) для видео
- ✅ Просмотр видео через встроенный HTML5 видеоплеер
- ✅ Удаление своих видео
- ✅ Редактирование своих видео
- ✅ Просмотр списка всех видео пользователя
- ✅ Просмотр списка всех видео (главная страница)
- ✅ Поиск видео по названию
- ✅ Фильтрация видео по категориям

### Комментарии
- ✅ Добавление комментариев под видео
- ✅ Удаление своих комментариев
- ✅ Просмотр всех комментариев под конкретным видео
- ✅ Отображение автора и времени создания комментария

### Профиль пользователя
- ✅ Просмотр профиля другого пользователя (его видео и информация)
- ✅ Просмотр своего профиля
- ✅ Отображение статистики (количество видео, подписчиков)

### Расширенные функции
- ✅ Лайки и дизлайки видео
- ✅ Подписки на других пользователей
- ✅ Счетчик просмотров видео
- ✅ Категории видео
- ✅ Современный и отзывчивый UI

## 🔧 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd JStrimix
```

### 2. Настройка базы данных

#### Вариант 1: Запуск PostgreSQL через Docker (рекомендуется)

Запустите PostgreSQL в Docker контейнере с учетными данными из проекта:

```bash
docker run --name jstrimix-postgres \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=mysecretpassword \
  -e POSTGRES_DB=postgres \
  -p 5432:5432 \
  -d postgres:15
```

Контейнер будет доступен на `localhost:5432` с учетными данными:
- **Username:** `postgres`
- **Password:** `mysecretpassword`
- **Database:** `postgres`

**Полезные команды для работы с контейнером:**
```bash
# Остановить контейнер
docker stop jstrimix-postgres

# Запустить контейнер снова
docker start jstrimix-postgres

# Удалить контейнер
docker rm jstrimix-postgres

# Просмотр логов
docker logs jstrimix-postgres
```

#### Вариант 2: Локальная установка PostgreSQL

Если у вас установлен PostgreSQL локально, создайте базу данных:

```sql
CREATE DATABASE postgres;
```

### 3. Настройка application.properties

Если вы используете Docker контейнер с креденшалами по умолчанию, настройки уже указаны в `src/main/resources/application.properties`:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/postgres
spring.datasource.username=postgres
spring.datasource.password=mysecretpassword
```

Если вы используете другую конфигурацию, отредактируйте файл `src/main/resources/application.properties` соответственно.

### 4. Создание директории для загрузок

Приложение создаст директорию `uploads` автоматически, но вы можете создать её вручную:

```bash
mkdir uploads
```

### 5. Сборка проекта

```bash
./mvnw clean install
```

### 6. Запуск приложения

```bash
./mvnw spring-boot:run
```

Или используйте Maven Wrapper для Windows:

```bash
mvnw.cmd spring-boot:run
```

Приложение будет доступно по адресу: `http://localhost:8080`

## 🗄 Модель данных

### Основные сущности:

- **User** - пользователи системы
- **Video** - видео
- **Comment** - комментарии к видео
- **Category** - категории видео
- **Subscription** - подписки пользователей
- **VideoLike** - лайки/дизлайки видео
- **VideoView** - просмотры видео

## 🔐 Безопасность

- Пароли хранятся в зашифрованном виде (BCrypt)
- CSRF защита (можно включить для production)
- Аутентификация через Spring Security
- Авторизация на основе ролей (USER, ADMIN)

## 📝 API Endpoints

### Публичные эндпоинты:
- `GET /videos` - список всех видео
- `GET /videos/{id}` - просмотр видео
- `GET /videos/{id}/video` - получение видеофайла
- `GET /videos/{id}/preview` - получение превью
- `GET /profile/{username}` - просмотр профиля пользователя

### Требующие аутентификации:
- `GET /videos/upload` - форма загрузки видео
- `POST /videos/upload` - загрузка видео
- `GET /videos/{id}/edit` - форма редактирования видео
- `POST /videos/{id}/edit` - обновление видео
- `POST /videos/{id}/delete` - удаление видео
- `POST /videos/{id}/like` - лайк/дизлайк видео
- `POST /comments/create` - создание комментария
- `POST /comments/{id}/delete` - удаление комментария
- `POST /profile/{username}/subscribe` - подписка на пользователя
- `POST /profile/{username}/unsubscribe` - отписка от пользователя
